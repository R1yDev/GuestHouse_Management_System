# Dar Haja Zekia Guesthouse Management

A simple guesthouse booking dashboard for managing reservations, house availability, boat trips, and guest information.

## Project Description

This project helps manage bookings for Dar Haja Zekia, a guesthouse with multiple house types and optional boat trip services. The system lets the admin:

- add new bookings
- edit existing bookings
- cancel bookings
- view daily activity
- check house availability
- manage stay and boat-trip reservations
- export and import booking data as JSON
- keep bookings saved in the browser using local storage

## Features

- Calendar view for house availability
- Booking table with filters
- Guest details popup
- House type filtering
- Daily arrivals, departures, and staying guest overview
- Support for:
  - Stay bookings
  - Boat trip bookings
  - Stay + boat bookings
- Advance payment tracking
- Notes for each booking
- JSON backup and restore

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons
- Browser localStorage

## Project Structure

- `index.html` or main page file: main application layout
- `style.css`: styling and layout
- `script.js`: booking logic, rendering, filters, storage, and actions
- `img/`: project images

## How to Use

1. Open the project in a browser.
2. Select a service type (stay, boat, or stay + boat).
3. Fill in the booking form.
4. Save the booking.
5. Use the calendar and table to manage reservations.

## Notes

This project is a front-end static app and does not require a backend server.
Bookings are stored locally in the browser using localStorage, so they remain available after refresh.
